# Info Pibes S.A
Contenido de las prácticas:
## Práctica 1 
Diseño y desarrollo de un Sistema de Información sobre una temática (Red social).

- Nombre del sistema
- Descripción de cada subsistema.
- Desarrollo de requisitos funcionales, acompañados de sus restricciones semánticas.

## Práctica 2 :WHEEL:
Diseño de diagramas de flujo de datos y de esquemas externos para cada subsistema.
- DFDs de cada subsistema (Caja negra, armazón, DFD1 de cada susbsistema)
- Esquemas externos de todos los procesos y almacenes de DFD0 y DFD1
- Esquema E/R del sistema
- Tablas del esquema E/R
- Dependencias funcionales, proceso de Normalización realizado yconjunto de tablas obtenido de dicho proceso, junto con las claves primarias y externas correspondientes.

>Caja negra: Se concibe el SI como un solo proceso, conectado con todos los agentes externos y flujos de datos

>Esquema armazón o DFD0: Cada subsistema representado como un sólo proceso, con flujos de datos con la/s base/s de datos
