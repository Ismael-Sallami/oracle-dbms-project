\section{Disparadores del Subsistema de Usuarios (Fernando)}


\subsection{Trigger: Prevención de Auto-Relación entre Usuarios}
\textbf{Descripción:} Este disparador aplica una regla fundamental (\textit{Business Rule}): un usuario no puede establecer una relación consigo mismo. Esta validación previene inconsistencias lógicas en el modelo y evita que se registren relaciones inválidas que podrían perjudicar el funcionamiento del sistema.

\textbf{funcionamiento:} Se ejecuta antes de insertar o actualizar (\texttt{BEFORE INSERT OR UPDATE}) sobre la tabla \texttt{AMISTAD}. Comprueba que los identificadores de ambos usuarios son distintos. Si se detecta igualdad, el disparador bloquea la operación y lanza una excepción mediante \texttt{RAISE\_APPLICATION\_ERROR}.

\begin{lstlisting}[language=SQL, caption={Trigger TRG\_AMISTAD\_NO\_AUTO}]
CREATE OR REPLACE TRIGGER TRG_AMISTAD_NO_AUTO
BEFORE INSERT OR UPDATE ON AMISTAD
FOR EACH ROW
BEGIN
  IF :NEW.IDUSUARIO1 = :NEW.IDUSUARIO2 THEN
    RAISE_APPLICATION_ERROR(-20001, 'No se permite que un usuario sea amigo de sí mismo.');
  END IF;
END;
/
\end{lstlisting}
