\section{Primer requisito funcional}
\textbf{\textcolor{rojo}{\underline{RF1-U:}}} Crear usuario. 

\textbf{\textcolor{rojo}{\underline{Descripción:}}} Permite a un visitante crear un usuario en el sistema, asignándole un nombre de usuario y una contraseña.
Opcionalmente, puede añadir una imagen de perfil y/o una breve biografía. 

\textbf{\textcolor{rojo}{Entrada:}} Agente externo: visitante. Acción: solicitar inserción.
Requisito de datos de entrada \textcolor{azul}{RDE1.1}. 
\textbf{\textcolor{rojo}{BD:}} Requisito de datos de escritura \textcolor{azul}{RDW1.1}. 

\textbf{\textcolor{rojo}{Salida:}} Agente externo: visitante. Acción: confirmación resultado.
Requisito de datos de salida: ninguno.
\pagebreak

\textcolor{azul}{\textbf{RDE1.1:}} Datos de entrada de crear usuario. 
\hspace*{1cm} Nombre de usuario: Cadena de caracteres (20)
\hspace*{1cm} Correo electrónico: Cadena de caracteres (50)
\hspace*{1cm} Contraseña: Cadena de caracteres (20)
\hspace*{1cm} Imagen de perfil: Cadena de caracteres (255)
\hspace*{1cm} Biografía: Cadena de caracteres (100) 

\textcolor{azul}{\textbf{RDW1.1:}} Datos almacenados del usuario. 
\hspace*{1cm} Los mismos que RDE1.1 
\hspace*{1cm} ID de usuario: Cadena de caracteres (40) 
\hspace*{1cm} Fecha de creación: Cadena de caracteres (40)
